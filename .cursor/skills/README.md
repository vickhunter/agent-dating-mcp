# Cupid live-build skills

Five skills, one per checkpoint. In a new empty git repo, invoke them in order. Each skill prints its prompt, builds that step, and stops.

| Say this | What it builds |
|---|---|
| Use the cupid-m0 skill | mcp-use scaffold, `fetch-weather`, local dev server |
| Use the cupid-m1 skill | register, profile, search, get-photo |
| Use the cupid-m2 skill | swipe, chat, propose-date, `GET /api/state` |
| Use the cupid-m3 skill | dark live wall |
| Use the cupid-m4 skill | Sofia, Marco, Priya, Leo, and `POST /api/reset` |

This repository is the finished reference. Fork it to read a skill when a step stalls, or to tweak the finished server. Do not deploy over https://dark-wave-s4cyg.run.mcp-use.com.
